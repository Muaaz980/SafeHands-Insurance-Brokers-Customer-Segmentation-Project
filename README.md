# SafeHands Insurance Data Cleaning

Public Repository: [SafeHands-Insurance-Data-Cleaning](https://github.com/Muaaz980/SafeHands-Insurance-Brokers-Customer-Segmentation-Project)

## Project Overview
This repository performs initial data cleaning and preprocessing on a public medical insurance dataset sourced from Kaggle/GitHub for the SafeHands insurance project to prepare clean customer data for downstream analysis.

## Repository Contents
* `data_cleaning.ipynb` — Jupyter notebook containing the step-by-step data inspection, handling missing values, and transformation workflow.
* `cleaned_customers.csv` — The processed and cleaned dataset output ready for analysis.
* `README.md` — Documentation providing an overview, repository structure, and instructions for running the project.

## Setup & Usage

### 1. Clone the Repository
bash
git clone [https://github.com/YOUR_USERNAME/SafeHands-Insurance-Data-Cleaning.git](https://github.com/YOUR_USERNAME/SafeHands-Insurance-Data-Cleaning.git)
cd SafeHands-Insurance-Data-Cleaning

### 2. Install Required Dependencies
Ensure you have Python installed, then install the necessary packages:

Bash
pip install pandas jupyter

### 3. Run the Notebook
Launch Jupyter Notebook to execute the data cleaning pipeline:

Bash
jupyter notebook data_cleaning.ipynb
